# Тортики & Тістечка — адаптивна галерея рецептів

Лабораторна робота 7–8: компонування вебсторінок, медіа-запити.

- Підхід: **mobile first**
- Мобільні (375–729px): базові стилі
- Планшети (730–1199px): `@media (min-width: 730px)`
- Десктоп (від 1200px): `@media (min-width: 1200px)`
- Компонування: CSS Grid (каркас сторінки, галерея, картки, кнопки) і Flexbox (сайдбар, футер)
- Фільтр за видом виробу працює **без JavaScript**: приховані `radio` + `label` + селектор `:checked ~`.
  Обраний вид залишається кольоровим, інші вироби стають чорно-білими.
